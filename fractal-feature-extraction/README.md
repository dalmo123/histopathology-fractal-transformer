# Fractal Feature Extraction

Este diretório contém os scripts utilizados para extração de descritores fractais e geração das representações utilizadas no modelo.

## Pipeline utilizado

O fluxo principal consiste em:

1. Cálculo dos descritores fractais (DF, LAC, PERC)
2. Geração dos vetores de características
3. Transformação dos dados em representações bidimensionais (RecPlot + Classical)

## Arquivo principal

- main_fractal_pipeline.mlx

## Observação

Apenas as etapas até a geração das representações RecPlot foram utilizadas nos experimentos do TCC. Outras partes do código foram mantidas para fins exploratórios.
